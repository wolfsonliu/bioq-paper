**Figure S6.** Serverless vs dedicated GPU: monthly cost break-even. Monthly cost
as a function of duty cycle, comparing bioq's pay-per-use serverless model (linear
in duty cycle) against a dedicated A100 (flat amortized line). The crossover marks
the break-even duty cycle (~8.8 % for an amortized A100; ~52 % for a persistent
cloud VM), with the shaded band showing the price-sensitivity sweep. Below the
crossover, serverless is cheaper; above it, owned hardware wins.
